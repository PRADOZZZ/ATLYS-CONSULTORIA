# ATLYS — Publicação

Esta pasta está preparada para Vercel sem alteração visual do site.

## Vercel
- Framework Preset: **Other**
- Root Directory: a pasta em que `index.html` e `vercel.json` ficam na raiz
- Build Command: deixe vazio
- Output Directory: deixe vazio
- Install Command: deixe vazio

Não há funções serverless: o site é estático e as imagens dos aparelhos são carregadas direto das fontes cadastradas (com fallback e placeholder local).

## Antes de apontar o domínio oficial
1. Confirmar internamente a autorização/licença das fotos de produtos usadas no catálogo.
2. Revisar juridicamente `privacidade.html` e `termos.html`.
3. Confirmar que `atlysconsultoria.com.br` será o domínio canônico definitivo.
4. Fazer um envio real de teste via WhatsApp em desktop e celular.

## O site não processa pagamento
O carrinho é uma solicitação comercial. O visitante é direcionado ao WhatsApp para confirmar disponibilidade, preço e condições.
